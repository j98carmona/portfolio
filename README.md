# Portfolio de Jorge Carmona

Sitio web de portfolio personal creado con HTML5 y CSS3 como trabajo final del máster en programación web.

## Enlace a la web

https://j98carmona.github.io/portfolio/

## Páginas

- **Inicio**: presentación, servicios y proyectos destacados.
- **Portfolio**: galería de proyectos en miniaturas.
- **Presupuestos**: formulario para solicitar un presupuesto.
- **Contacto**: datos de contacto, formulario y mapa.
- **Aviso legal**: datos del titular y propiedad intelectual.

## Estructura del proyecto

```
mi-portfolio/
├── index.html
├── css/
│   └── estilos.css
├── images/
└── views/
    ├── portfolio.html
    ├── presupuestos.html
    ├── contacto.html
    └── aviso-legal.html
```
